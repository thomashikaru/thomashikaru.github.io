# Google Scholar sync

Publications are loaded from `_data/publications.yml`, generated by `scripts/fetch_scholar.py`.

## Automatic updates

GitHub Actions workflow `.github/workflows/update-scholar.yml` runs weekly (Mondays 06:00 UTC) and can be triggered manually from the Actions tab.

**Note:** Google Scholar frequently blocks requests from GitHub Actions servers (`MaxTriesExceededException`). When that happens, the workflow exits successfully and **keeps** the existing `_data/publications.yml` in the repo. Your site still builds; only automatic updates are skipped.

**Reliable updates:** run `python scripts/fetch_scholar.py` on your Mac (home network), then commit and push `_data/publications.yml`.

Scholar user ID is set in `_config.yml` (`gOucDpQAAAAJ`). You may optionally add a `SCHOLAR_USER_ID` repository secret to override it.

## Preview the site locally

macOS ships with Ruby 2.6, which is too old for this project’s Jekyll setup. Use **Homebrew Ruby** instead:

```bash
brew install ruby   # if needed
chmod +x bin/serve
./bin/serve
# open http://127.0.0.1:4000
```

Or put Homebrew Ruby on your `PATH` for this shell, then use `bundle` as usual:

```bash
export PATH="/opt/homebrew/opt/ruby/bin:$PATH"   # Apple Silicon
# export PATH="/usr/local/opt/ruby/bin:$PATH"  # Intel Homebrew
bundle install
bundle exec jekyll serve
```

## Local refresh

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r scripts/requirements.txt
python scripts/fetch_scholar.py
```

## PDF links

Scholar does not provide stable PDF URLs. Add or update entries in `_data/publication_pdfs.yml`, keyed by normalized title (see `title_key` in `publications.yml`).
